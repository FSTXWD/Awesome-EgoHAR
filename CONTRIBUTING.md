# Contributing

Add each paper or dataset once in assets/registry, with a stable ID and a direct, canonical URL. Prefer a publisher, paper, dataset, challenge, or project page. Avoid search result links and guessed URLs.

For papers record title, year, scope, position, device, raw modality, and topic. For datasets record name, sensing configuration, tasks, and access page. Use an empty array or null for unknown details; do not fill gaps by inference.

The public Markdown views should link the title itself to the same URL. Keep entries concise and verify that a link identifies the stated resource. Do not upload third-party code, raw datasets, local helper scripts, or private notes.
