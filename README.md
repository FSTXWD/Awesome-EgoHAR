## Scope and dimensions

This collection focuses on human activity recognition (HAR) when the input is first-person video or a sensor worn or carried by the person. It includes clip/window classification and continuous activity recognition when activity labels are localized in time.

We describe each study through the same input → model → output view:

| Stage | Dimensions recorded |
| --- | --- |
| Input | Body position and device; sensing modality; signals available at inference; extra modalities used only for training |
| Model | Signal representation (time series, frequency features, frames, tokens, or latent embeddings); supervision and learning strategy |
| Output | Activity task and granularity: window/clip class, continuous segment/localization, or language-grounded activity output |

The main scope holds HAR as the target and lets readers compare input configurations, representations, and learning strategies. A final group retains studies whose activity-recognition output also includes language, retrieval, or text responses. “Egocentric” here includes body-worn and carried sensors as well as first-person cameras. Pure sound-event detection, general video localization, and 3D scene reconstruction are kept in the resource tables when useful, but do not enter the main HAR paper matrix.

## Open challenges

- Choosing sensor positions and devices without sacrificing comfort or coverage.
- Aligning asynchronous modalities and recovering event boundaries from sparse labels.
- Handling changing people, devices, environments, and missing modalities.
- Reporting latency, power, privacy, and other deployment costs alongside recognition accuracy.
